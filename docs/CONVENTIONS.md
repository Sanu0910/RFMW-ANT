# Conventions used in all projects

## Units and frames
- All geometry is in **mm**, and frequencies are quoted in GHz.
- Each project states its coordinate frame in its geometry library (`msgeom.py`, `nsgeom.py`, `rbageom.py`) and in its guide.

## DXF
- One DXF layer per metal layer, named after the paper (L1/L2/L3, TOP/MID/BOT, M1–M4).
- `*_SLOT` and `*_CUTOUT` layers hold apertures to **subtract** from the metal layer of the same name.
- `VIA`: drill circles. The span is given in the BOM / DRC or in the guide.
- `PORT`: thin rectangles marking the HFSS port reference plane.
- `SILK_*`: silkscreen. `ASSY_*`: component bodies and reference designators. `FAB`: stack-up and fabrication notes.
- Each DXF has a `_preview.png` rendered from the same geometry.

## HFSS import
1. Modeler → Import → DXF.
2. Set each layer's elevation from the stack-up table in that project's guide.
3. Subtract the cutout layers, then assign PerfE (or finite-conductivity Cu for the final run).
4. Model lumped components as lumped RLC sheets at the positions in `BOM_and_placement.csv`.

## Assumptions
Every value not given in a paper is marked `[ASSUMED]` in the geometry code and listed in the guide's assumptions table, together with how to settle it in simulation.

## Regenerating
- Every DXF, preview, BOM and DRC report is generated by the project's Python builder (`build_*.py`).
- To regenerate: edit the parameters in the geometry library and run the builder again.

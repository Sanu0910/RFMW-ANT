C-band 6×6 Dual-Polarised Stacked-Patch Array

S11 / VSWR root-cause analysis with openEMS (FDTD) · project 15_cband-6x6-dualpol-stacked-patch_match-debug · 2026-10-29
Inputs: F_CU.dxf, IN2_CU.dxf, GND.dxf, C_Band_Stackup.pdf · Target band 4–7 GHz

1. Summary

Problem reported: broadside gain is as expected, but the input match is poor; VSWR never gets below 3:1 over 4–7 GHz.
Answer, in short:
  1. The radiating element itself is narrow-band. One element cut out of the board, with its own feed stubs, is matched (VSWR ≤ 3) only from about 5.35 to 6.26 GHz, which is ~16 % bandwidth. The 4–7 GHz target is 54 %. Outside that window most of the power is reflected, so the realised gain drops even though the element still radiates well (its gain referred to accepted power is 8.7–9.8 dBi). That is exactly "gain is OK but VSWR is bad".
  2. The driven patches are edge-fed with no matching. Each feed joins the radiating edge through a 2.48 mm (50 Ω) stub that is only a few mm long. A radiating edge has a resistance of a few hundred ohms. Without the parasitic patch the element is not matched anywhere in 4–7 GHz (worst-case VSWR above 8 everywhere). The parasitic patch is the only reason there is a usable window around 5.8 GHz.
  3. The driven and parasitic resonances merge into one. The parasitics (16.2–17.8 mm) are about the same size as the driven patches (17.07 mm). The simulation shows a single resonance loop, and the matched window simply follows the parasitic size: 16.2 mm gives a window around 5.8 GHz, 18.6 mm moves it down to about 5.0–5.5 GHz, and the window stays narrow in both cases. A broadband stacked patch needs two separate, properly coupled resonances inside the band. This geometry does not have them. Because the parasitics are graded row by row (16.2 to 17.8 mm), each row is matched at a slightly different frequency, so at any one frequency part of the aperture is mismatched.
  4. No feed-network change can fix this on its own. A best-case circuit optimisation on the simulated element impedance (line + transformer + stub) still leaves a worst-case VSWR of about 9 across 4–7 GHz (section 5).

3. How it was simulated

  • Solver: openEMS v0.37 (FDTD), Gaussian excitation 2.5–8.5 GHz, 8-cell PML on all sides, near-field to far-field box for broadside gain.
  • Geometry read directly from the DXFs (cbgeom.py). Copper is modelled as zero-thickness PEC. RT5880: εr 2.2, tanδ 0.0004. FR4: εr 4.5, tanδ 0.02. The gap is air.
  • Element model (sim_element.py): the row-1/col-1 element is clipped out of In2.Cu with both edge feeds, up to where each becomes a 0.73 mm (100 Ω) branch. Each branch ends in a 100 Ω lumped port. |S11| there is the reflection the element sends into its own branch of the network, and it does not depend on where along the lossless line the cut is made. It sits on a 60 × 60 mm ground with 0.25 mm in-plane cells (2.9 M cells).
  • Full array (sim_array.py): the whole board with both ports, 0.5 mm in-plane cells (12 M cells).
  • Matching study (match_study.py): circuit optimisation on the simulated element impedance.

  • B (no parasitic): the bare edge-fed patch is badly mismatched at every frequency. The edge feed was never transformed to the line impedance.
  • C–E (larger parasitic): the matched window moves down in frequency as the parasitic grows, and it gets narrower (16 % at 16.2 mm, 12 % at 18.6 mm, 4 % at 20.3 mm, none at 21.9 mm). Resizing the parasitic tunes where the element works. It does not make it work over 4–7 GHz.

No. Even a series line plus a transformer plus a shunt stub leaves a worst-case VSWR of about 9. The element's own reactance swing across 4–7 GHz is too large to compensate with a passive network (Bode–Fano limit). The fix has to be made in the radiator.

6. Full array

Full-array run still in progress. The complete 276.86 mm board (12 M FDTD cells, both 36-way networks, 72 feed points) decays slowly because of the long corporate feed lines. Its S11/S22/S21 will be added to this report in a later revision. The element-level results below already explain the measured behaviour: the array input match cannot be better than the match of the elements it is feeding through a reciprocal, near-lossless corporate network built from 100 Ω branches and 70.7 Ω quarter-wave transformers.

8. What to change

  1. Hold the 4 mm air gap tightly. Check the spacer height on the built board: a 0.3 mm error in a 4 mm gap moves the driven-parasitic coupling noticeably.
  2. Re-tune the element as a true double-resonance stacked patch in a unit-cell (periodic) simulation before touching the network:
    • Separate the two resonances: one near 4.5 GHz and one near 6.5 GHz. That needs the driven patch, the parasitic and the gap (3–6 mm) to be tuned together. Scaling one patch alone only moves a single narrow window (variants C–E).
    • Use the same parasitic size on every row unless a row-by-row taper is deliberately part of the design. The present 16.2–17.8 mm grading detunes the rows from one another.
    • Aim for a tight loop around the chart centre over 4–7 GHz, then use one quarter-wave transformer per element to bring it to 100 Ω.
  3. Change the feed type if 4–7 GHz at VSWR < 2 is required. 54 % bandwidth is very hard for a direct edge-fed stacked patch. Proven routes for this bandwidth are:
    • aperture-coupled stacked patch (H-shaped or cross slots for dual polarisation), with the feed on a separate layer below the ground;
    • L-probe or meandered-probe feed into a thick air/foam patch;
    • a probe-fed stacked patch with capacitive-disc compensation.
    All of these also improve V/H isolation; the edge feeds here couple at only about −7 dB at 7 GHz.
  4. If you keep the edge feed: add an inset or a λ/4 transformer from the edge resistance (100–300 Ω) to 100 Ω on each feed. That centres the existing narrow band on one frequency. It will not widen it to 4–7 GHz.
  5. Reduce the pitch to ≤ 0.7 λ at 7 GHz (≈ 30 mm) if the upper band must be free of grating lobes. This needs the smaller element that a wideband feed allows.
  6. Measurement check: measure S11 of one element on a test coupon and the bare network loaded with 100 Ω resistors. That separates element and network on the bench and confirms this analysis.

9. Limits of this analysis

  • The element was simulated alone on a 60 mm ground. Mutual coupling in the array shifts the embedded impedance a little. The full-array model includes it.
  • The full-array mesh (0.5 mm) snaps the 0.73 mm lines to 0.5 or 1.0 mm, which shifts the network's own resonances by a few percent.
  • Copper thickness, solder mask, connector transitions and the spacers holding the 4 mm gap are not modelled.
  • No measured data was available. The comparison is with the reported symptom (VSWR > 3, gain OK).
